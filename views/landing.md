# Exploring local housing data to spark conversation

This application uses Multiple Listing Services (MLS, aka real estate) data to try to understand what housing is currently available in Exeter, NH. (Other towns coming soon.)

The data is very "noisy" - there are inconsistencies and outright errors in the data. I am working to address those issues but the data will never be 100% accurate.

Please use the navigation buttons to the left to go to various pages.

The "About" and "Background" pages provide more information about this application and why I am developing it.
